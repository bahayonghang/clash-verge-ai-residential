# 家宽页面排版与表格样式重构

## Goal

重排家宽页（`residential-monitor/src/components/features/residential/`）的信息层级、布局分组与表格样式，让主要信息一屏可扫、表格易读；**不改变任何数据口径、交互功能和文案内容**。顺带把页面内手写的表格 class 模式收敛为共享样式/组件，并增强共享组件（StatCard / OverviewCard / SortableTh）的样式能力，但不改变其他页面现有调用的行为。

## Background

当前页面问题（截图 + 源码交叉确认）：

1. **信息层级坍塌**：页标题 `text-lg`、区块标题 `text-sm font-semibold`、子区块同为 `text-sm`，层级仅靠字重区分；区块间只有 `space-y-8` 空白，无卡片/分隔容器。`AggregateSection` 内嵌的 `ShareReadout` 又开 h2，层级嵌套错误。
2. **说明文字淹没数据**：每个区块标题下挂 1~3 行 `text-xs text-muted-foreground`（口径说明、采样时间、分母说明、named SQL、策略版本），首屏灰色小字多于数据。口径文案是产品原则（口径分开、未知保持未知），**必须保留**，但视觉权重需降档归位。
3. **表格样式失控**：
   - 占用表、占比表、排名表全部 `w-full` 拉伸，名称列贴左、数值列漂到最右，行扫描距离过长；
   - 对齐不一致：排名表数值右对齐，占用表/占比表左对齐（`monitor-section.tsx`、`share-readout.tsx`）；
   - 行分隔仅 `border-border/40` 细线，无斑马纹、无 hover（仅 `TrendTable` 有），表头与正文同字号；
   - 占比表 2 行、占用表常 1 行，各占一整条全宽表格；
   - `TrendTable` `max-h-56` 内滚动 + sticky 表头，与外部长页滚动嵌套打架。
4. **图表与表格冗余脱节**：排名 RankBar 与表格重复同一份数据，图表标签字号过小、域名截断，条形配色与表行无视觉对应；趋势面积图很大而配套表格被压进小框。
5. **控件与状态裸排**：排名卡右上角「下行/上行 + 10/20/50/100」两组切换器挤在一起无分组；报告区 Switch、按钮、状态文字、CoveragePanel、CapabilityPanel、ExportPanel 全部裸排无容器；状态文字（「尚未运行报告」、统计窗口）以普通段落混排。
6. **令牌不一致**：`StatCard` 颜色硬编码 `#3B82F6/#A855F7/#8B5CF6/#06B6D4`，不走主题令牌，Latte 浅色主题下会脱节；表格未遵循 DESIGN.md「等宽数字 + 语义 table + 可见排序图标」统一规格。

## Requirements

- R1 布局方向：**单列 + 卡片分组**。保持现有区块先后顺序，用卡片容器与明确的标题层级把区块分组收紧；不引入双栏网格、不改成大留白营销卡片，保持专家工具密度（DESIGN.md 约束）。
- R2 修复标题层级：页标题、区块标题、子区块拉开字号/字重档差；修正 `ShareReadout` 的 h2 嵌套，使其从属于家宽流量统计区块；主区不重复侧栏已承担的认页职能。
- R3 说明文字降权归位：口径/采样/分母等说明文案保留原文，统一收敛到固定位置（区块标题旁的 note 区），字号颜色降档，不与数据争注意力。
- R4 表格样式收敛：页面内三张手写表格（占用、占比、排名）统一为一致的表格规格——数值列一律右对齐 + `tabular-nums`、表头与正文拉开档差、清晰的行分隔/hover、列距收紧（表格不再无脑 `w-full` 拉伸，或数值列靠拢）。收敛成果沉淀为共享表格组件或共享 class，概览页 `category-table.tsx` 可一并接入但非强制。
- R5 小表格改紧凑形态：占比表（2 行）等超小表格允许改为更紧凑的读数形式（如定义列表/紧凑行），不占全宽。
- R6 图表-表格联动：排名图表标签可读性（字号/截断）优化；图表与表格的视觉对应关系明确（如共享色序）；趋势区面积图与表格的比例关系调整，消除嵌套滚动的不适感（保留 TrendTable 内滚动功能本身可接受，但需视觉上是一个整体容器）。
- R7 控件分组：排名卡的 direction / TopN 两组切换器视觉分组清晰；报告区操作（Switch + 运行按钮 + 状态）与 CoveragePanel / CapabilityPanel / ExportPanel 装入卡片容器，状态文字有固定位置。
- R8 令牌一致：`StatCard` 的硬编码颜色改为走主题令牌（chart-1..5 或语义令牌），深浅四主题下均正确；表格规格对齐 DESIGN.md 的 Data table 条目。
- R9 **功能不动**：不改 DTO、hooks、IPC、数据流、排序/筛选/分页逻辑、i18n 文案 key 与文案内容、交互行为（排序点击、切换器、运行报告、导出等）。仅允许为样式目的调整 DOM 结构与 class，以及 i18n 纯展示层的布局相关 class。
- R10 共享组件增强不破行为：`StatCard`/`OverviewCard`/`SortableTh` 的增强对既有调用方（概览、维度、报告页）视觉变化须最小且向后兼容；新能力以可选 props 或新组件形式提供。

## Acceptance Criteria

- [ ] AC1 家宽页首屏（1200×800 默认窗）能同时看到：实时监控三指标卡、方向热点卡、占用读数；主要数值（mono 指标值）是首屏视觉重心，说明小字不与之竞争。
- [ ] AC2 页面标题 / 区块标题 / 子区块三级在截图对比中肉眼可区分（字号或字重至少两档差）。
- [ ] AC3 全部表格：数值列右对齐 + `tabular-nums`；表头与正文有档差；行 hover 或等效行定位辅助；不再出现「名称贴最左、数值漂最右」的超宽扫描行（占比、占用小表格改为紧凑形态）。
- [ ] AC4 排名图表标签不再大面积截断（当前 TopN 下标签可读），图表与表格色序一致或表格行有对应色标识。
- [ ] AC5 报告区：操作行、状态、三个 Panel 都在卡片容器内；「尚未运行报告」等状态文字位置固定、样式为状态样式而非正文段落。
- [ ] AC6 `StatCard` 颜色全部来自主题令牌；切到 Latte 浅色主题目测无脱节色块。
- [ ] AC7 功能回归：家宽页现有测试（`index.test.tsx`、`aggregate-section.test.tsx`、`trend-table.test.tsx`、`report-section.test.ts` 等）全部通过；排序、方向切换、TopN 切换、运行报告、导出预览的交互行为与改前一致。
- [ ] AC8 概览、维度、报告等其他页面截图对比无明变化（共享组件增强未外溢），或仅有经用户确认的微调。
- [ ] AC9 `npm run lint` 与类型检查通过； impeccable detect 无新增违规。

## Out of Scope

- 家宽页以外页面的布局重构（概览页仅在表格收敛顺手接入时触碰）。
- 数据口径、报表查询、告警、设置等任何后端/IPC 逻辑。
- 新增文案或改写既有文案（位置与样式可调，文字不动）。
- 双栏/响应式大改版、暗色以外的视觉世界更换。

## Notes

- 方向已确认：范围 = 家宽页 + 表格样式收敛 + 共享组件增强；布局 = 单列 + 卡片分组。
- 视觉权威：DESIGN.md（深色侧栏工作台、neko 令牌、专家工具密度）与 `.impeccable/surfaces/residential-monitor-src-main-ts.md`（Operate 模式，质量条对齐 Clash Verge Rev）。
- 产品原则红线：缺口/未知显示「未知」不填零；meter、可归因、缺口口径各自成项；说明文案可降权但不可删除。
