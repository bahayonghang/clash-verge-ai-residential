# 家宽流量监控 Tauri 桌面应用

## 目标与用户价值

在 `residential-monitor/` 建设一个可长期运行的 Windows 11 本地桌面应用，持续采集 Clash Verge Rev / mihomo 的全部连接事实，以用户选择的代理组或节点作为重点分类，提供实时监控、历史分析、报告导出和主动告警。

产品用于观察和解释流量，不把采样结果冒充代理商权威账单。用户应能回答：

- 当前哪些连接、域名、进程、规则和链路正在产生流量？
- 重点分组占全局流量多少，何时出现异常峰值或误分流？
- 指定小时、日期、月份或自定义区间内，流量由哪些分类、域名、进程、规则和链路构成？
- 报告覆盖了哪些时段，哪些时段因应用未运行、休眠、断线或存储故障而缺失？

## 背景与已确认事实

- 本仓库扩展脚本把部分 AI 流量经 `AI-家宽` → `家宽-SOCKS5` 链路送往住宅代理；用户实际名称可能不同，也可能存在多个相关分组或节点。
- Clash Verge Rev 自带 Connections 页只展示当前全量连接，缺少可配置重点分类、跨重启历史、报告、保留策略与告警。
- mihomo `/connections` 只提供活跃连接快照和累计计数；连接消失后的尾部流量、断线期间流量及应用启动前流量无法按连接补回，因此历史是带覆盖说明的观测下界。
- TCP External Controller 是受支持接入；Clash Verge Rev 内部 named pipe 只做版本化、尽力兼容。管道不校验 secret，安全依赖 Windows ACL；固定管道名和 `chains` 顺序都不是稳定契约。
- 完整 v1 仅正式支持 Windows 11；选择“登录后托盘常驻”而不是 Windows Service。

## 用户场景

1. 用户打开概览，立即看到全局与重点分类速率、活跃连接、采集健康和今日用量。
2. 用户按分类、域名、进程、规则或链路筛选实时连接，必要时发送关闭单条连接请求。
3. 用户按小时、日、月或自定义范围查看趋势、Top N、周期对比和采集覆盖。
4. 用户导出与应用内查询口径一致的 CSV、JSON 或可打印 HTML 报告。
5. 用户关闭窗口后应用继续在托盘采集；采集断线、存储故障或流量阈值触发时收到告警。
6. 用户调整重点目标及优先级，并在明细保留期内用新条件重新分析历史。

## 功能需求

### R1. Windows 桌面生命周期与分发

- 使用 Tauri 2 构建 Windows 11 桌面应用，采用 NSIS current-user 安装包。
- 单实例运行；关闭主窗口只隐藏到托盘，不停止采集。
- 托盘提供打开窗口、暂停 / 继续采集、立即重连、状态摘要和明确退出。
- 首次引导由用户确认是否启用登录自启动；启用后使用后台参数启动，不主动弹窗。
- 通过 GitHub Releases 手动下载升级，v1 不做应用内自动更新；升级必须保留设置、凭据引用和历史数据。

### R2. 控制器发现、接入与恢复

- 支持 TCP External Controller 与 Windows named pipe 两种传输。
- TCP 是受支持路径，使用 Bearer secret；secret 不出现在 URL、日志、数据库、Channel 或导出中。
- named pipe 是尽力兼容路径：自动发现必须验证服务端身份和 `/version` 能力，不发送 secret，不硬编码永久管道名；不兼容时引导用户启用 TCP。
- 手动控制器配置优先于自动发现；支持测试连接、重新发现、取消中的连接尝试和指数退避重连。
- 状态至少区分：连接中、已连接、TCP 鉴权失败、管道访问拒绝、管道忙超时、端点不存在、协议不兼容、核心重启、系统休眠 / 采集缺口、存储故障。

### R3. 全量连接采集与观测核算

- 持久化控制器提供的全部连接，而非只保存重点目标连接。
- 保存连接完整元数据：域名、源 / 目标 IP 与端口、网络类型、进程名、完整进程路径、规则、规则载荷、`chains` 与 `providerChains`；字段允许未知或缺失。
- 以控制器 epoch 与连接 ID 形成内部会话身份；首次观察值只作为基线，不把应用启动前累计量计入历史。
- 使用相邻快照非负增量核算；核心重启、计数器回退、断线、休眠、暂停、应用退出和存储失败必须形成显式覆盖区间或缺口，不能写成零流量。
- 全局、重点分类与“其他连接”必须来自同一批连接事实；速率与占比使用相同时间窗口。
- 历史和报告必须标注“观测下界”、覆盖率、最后采样时间和缺口原因。

### R4. 重点目标、分类与策略版本

- 从 `/proxies` 拉取代理组和节点供多选，允许手动补充名称；首次运行建议名称含“家宽”的条目。
- 目标可拖拽排序。连接命中多个目标时，用户优先级最高的命中项是唯一主分类，全部命中项作为标签。
- 分类不得依赖 `chains` 数组首尾或展示顺序；保留原始链用于诊断。
- 每次目标、优先级或分类规则变化生成策略版本。30 天明细期内可按当前策略重算；明细过期后的汇总需标明生成时使用的策略版本。

### R5. 实时监控与连接控制

- 概览分别展示 mihomo 控制器 meter、可归因观测总量、重点分类、其他连接和未归因差额的上下行速率 / 累计，并展示活跃连接数、采集覆盖与健康状态；不得把控制器 meter 与逐连接可归因事实混称为同一个“全局”口径。
- 活跃连接表支持分类、域名、进程、规则、链路、网络类型和时间筛选，支持排序与分页 / 虚拟化。
- 连接详情展示完整元数据、累计字节、当前速率、持续时间、主分类与全部命中标签。
- 支持关闭单条当前连接。`204` 只显示“已发送关闭请求”，待后续快照确认连接消失；不提供关闭全部连接。

### R6. 历史分析与应用内报告

- 时间范围支持小时、指定日期、近 7 / 30 日、自然月和自定义区间；所有持久时间使用 UTC，展示时按用户本地时区转换。
- 提供总量趋势、上下行拆分、重点分类占比、Top 域名、Top 进程、Top 规则、Top 链路、连接数、活跃时长和周期对比。
- 30 天明细期内支持下钻到连接会话并按新目标策略重新分析；更老数据使用小时 / 日汇总，并明确策略版本和可下钻边界。
- 所有应用内数字、图表和导出共享同一后端查询与投影，不在前端重复实现统计口径。

### R7. 报告导出

- 按当前查询条件导出 CSV、JSON 和可打印 HTML；v1 不输出 PDF 或 Excel。
- 导出包含时间范围、时区、单位、筛选条件、策略版本、schema / 数据版本、生成时间、覆盖率与缺口说明。
- 导出前允许选择字段，并对域名、IP、进程路径提供脱敏预览；secret 永不进入导出。
- 导出汇总必须与应用内同一查询一致。

### R8. 分层保留、备份与恢复

- 默认保留：连接会话与稀疏分钟级明细 30 天（v1 可配置上限 90 天）；精确高基数维度（域名、进程、规则、链路、网络类型）最多 13 个月；长期日汇总只保留可归因总量、历史主分类和覆盖率。告警历史 180 天；原始覆盖区间 13 个月；迁移与备份清单长期保留。
- 设置页显示按层真实占用、近期增长率、预计清理结果与保留期空间预测，允许在支持上限内调整期限和立即清理。
- 清理必须先生成并验证上层汇总，再删除下层事实；中断后可幂等续跑。
- schema 迁移前自动备份；支持用户手动备份和维护模式恢复。恢复失败不得覆盖当前可用数据库。

### R9. 告警

- 支持采集健康告警：控制器断线、TCP 鉴权失败、端点不兼容、采集缺口、存储 / 迁移 / 备份故障。
- 支持流量异常告警：按分类、域名或进程配置速率和周期用量阈值。速率阈值基于 60 秒滚动平均并需连续 3 次评估满足条件；周期用量窗口可选滚动 1 小时、用户本地自然日或自然月。
- 规则支持启停、冷却、恢复、静默时段和测试通知；状态与历史持久化。
- 应用内告警中心是权威记录，Windows 系统通知是尽力送达；通知失败不能丢失告警。

### R10. 设置、安全与隐私

- 首次引导完成控制器发现、连接测试、重点目标、登录自启动、保留策略、通知测试和本地隐私告知。
- TCP secret 使用 Windows Credential Manager 保存；配置只保存稳定引用和是否已配置，不保存明文。
- 数据、日志和导出默认只在用户本机；应用不加载远程内容，不发送遥测。
- 日志轮转并脱敏；诊断信息包含版本、传输、状态、采集与存储健康，不包含 secret 和原始敏感连接字段。
- 生产配置使用显式 CSP、最小 Tauri capability 和固定本地资源。

### R11. 界面与可用性

- 现代深色主题，与 Clash Verge Rev 协调但保持独立品牌；设计令牌统一配色、圆角、间距、字体、层级和状态色。
- 导航至少包含：概览、实时连接、分析报告、告警、设置 / 数据管理。
- 数字使用等宽数字排版；图表提供对应数据表、清晰单位和缺口可视化。
- 连接中、断线、鉴权失败、管道拒绝、协议不兼容、无数据、数据缺口、存储故障、迁移失败均有专门状态与恢复操作。
- 支持键盘操作、可见焦点、高对比文本和非颜色唯一编码。

## 技术与仓库约束

- 后端采用 Rust；前端采用 Vanilla TypeScript + Vite，不引入 UI 框架。构建产物全部本地打包，不使用 CDN 或远程运行时资源。
- 权威持久化采用 SQLite；JSON 只用于小型非敏感偏好或导出，不作为流量账本。
- 应用代码位于独立 `residential-monitor/` 子目录；根脚本继续保持 Node 18+、CommonJS、零依赖和现有复制粘贴运行契约。
- UI 文案、代码注释和子项目文档使用中文；构建元数据与既有英文文件遵循仓库约定。
- 真实控制器 secret、住宅代理信息、未脱敏连接日志和本地数据库不得进入仓库。
- 子项目必须有独立 Rust / TypeScript 质量门，并纳入 GitHub CI；根目录 `just ci` 继续通过。
- v1 只正式支持 Windows 11；系统能力通过清晰 seam 隔离，但 macOS / Linux 不进入 v1 验收。

## 非目标

- 不修改 Clash / mihomo 配置，不代理、重放或抓取流量内容。
- 不宣称严格计费精度，不计算费用、费率、币种、预算或代理商账单，不接入供应商 API。
- 不恢复应用安装前、应用未运行时或控制器无法观测时的连接明细。
- 不做 Windows Service、未登录用户会话采集或机器级 24×7 服务。
- 不做 macOS / Linux 发布，不做多控制器并行、非本机控制器、远程团队面板、云同步或外发遥测。
- 不做应用内自动更新、PDF / Excel 导出、定时邮件报告或可分享云链接。

## 验收标准

- **AC1 接入兼容**：Windows 11 真机在 TCP secret 正确 / 错误 / 为空，以及 Verge v2.5.2 管道、当前动态 sidecar / service 管道、ACL 拒绝和 pipe busy 注入场景下显示正确状态；私有管道不兼容时可回退 TCP。
- **AC2 核算正确**：录制帧覆盖首帧基线、数组乱序、连接消失、ID 重用、计数器回退、核心重启、跨小时、休眠和断线；每个时间桶满足 `可归因观测总量 = 各主分类 + 其他`。控制器 meter、正向未归因 gap 与反向 over-attributed 异常按同一 frame / epoch / 方向单独呈现，reset 首帧记未知，缺口不写成零。
- **AC3 策略可解释**：多目标命中只按用户优先级选择唯一主分类并保留全部标签；30 天内可用新策略重算，超过明细期的汇总显示原策略版本。
- **AC4 连续采集**：用户确认启用登录自启动后，后台启动进入托盘；关闭窗口、重建 WebView 不影响采集；暂停、继续和明确退出正确关闭覆盖区间并落盘。
- **AC5 实时体验**：10,000 条模拟活跃连接、1Hz、至少 30 分钟的短时峰值下实时摘要有序、内存有界，连接表可操作；该峰值不代表 30 天持续容量。单条关闭请求不因 mihomo 返回 `204` 而提前误报成功。
- **AC6 历史报告**：小时 / 日 / 月 / 自定义范围的总量、趋势、周期对比和覆盖率可查询；精确 Top 域名 / 进程 / 规则 / 链路在 13 个月高基数保留期内可用，更老数据明确只提供长期总量 / 分类 / coverage，应用重启后结果不变。
- **AC7 导出一致**：同一查询的 CSV、JSON、可打印 HTML 与应用内总计一致，并包含筛选、时区、策略、数据版本和缺口说明；敏感字段可选择或脱敏。
- **AC8 保留守恒**：默认明细 30 天、高基数精确汇总 13 个月、总量 / 分类 / coverage 日级长期；清理中断可续跑，raw → hourly / daily 汇总守恒。每一保留层声明支持的查询能力在汇总前后结果不变；能力过期后必须明确返回 capability 不支持，不能给出伪结果。
- **AC9 告警闭环**：断线 / 存储故障，以及配置的 60 秒滚动速率、滚动 1 小时 / 自然日 / 自然月用量阈值触发一次活动告警；冷却期不重复轰炸，恢复后记录恢复时间；通知失败时应用内记录仍完整。
- **AC10 安全隐私**：secret 只在 Credential Manager 和短暂 Rust 内存中出现；仓库、SQLite、日志、Channel、错误、诊断与导出均不含 secret；生产 CSP / capability 最小化。
- **AC11 数据恢复**：迁移前备份、迁移中断、数据库高于应用版本、checksum 不符、坏备份和恢复失败均 fail closed；当前可用数据库不被覆盖。
- **AC12 安装升级**：NSIS current-user 安装态的托盘、自启动、单实例、通知和卸载通过。首次 v1 使用 C0 冻结的早期安装包 / schema fixture 验证手动升级；后续版本改用上一正式 Release。升级后数据库、偏好和 Credential Manager 引用完整。
- **AC13 界面质量**：所有健康 / 空 / 错误 / 缺口状态有专门中文界面与恢复动作；键盘、可见焦点、对比度、数字和图表数据表通过走查。
- **AC14 工程质量**：Rust fmt / clippy / test、TypeScript typecheck / lint / test / build、安装态 smoke 和至少 24 小时稳定性测试通过；根 `just ci` 与 secret scan 通过。
- **AC15 数据库性能**：C0 以平均活跃连接 `A=50 / 250 / 1000` 的完整 30 天库冻结包含 `A / L / C / q`、维度基数和每帧变化比例的支持范围，并运行 10,000 活跃且全部连接计数每帧变化的短时峰值；记录每表 / 索引 B/row、DB / WAL、写放大、冷 / 热查询和 p50 / p95 / p99。达到支持上限、队列饱和或存储超时后必须显式进入 degraded coverage，不得静默丢账、缩短保留或把缺口写成零。

## 风险与延后项

- Clash Verge Rev 私有管道没有外部兼容承诺；TCP External Controller 是稳定回退，不承诺每个未来 Verge 版本都能零配置发现私有 IPC。
- 快照尾差和采集缺口无法按连接补回；产品通过覆盖率和“观测下界”表述管理，而不是伪造精确值。
- Rust SQLite binding 与 Windows Credential Manager binding 尚待实现前选型验证，必须证明捆绑 SQLite 版本、Backup API、许可、维护状态和错误映射。
- Windows 代码签名证书若发布时尚未具备，安装包会触发 SmartScreen；Release notes 必须如实说明，不能把未签名构建描述为已验证发布体验。
- 阻塞性产品问题：无。
