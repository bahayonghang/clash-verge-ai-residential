# 产品标记候选

Imagine 于 2026-08-25 生成。实施时从选定方案转成无损 PNG 真源，不能把 JPEG 打进 ICO。

Windows 11 开始菜单会再套 squircle，资产必须铺满正方形、不要预做圆角。

| 方案 | 文件 | 图形 | 16px 可读性 | 已知问题 |
|---|---|---|---|---|
| A | `A-gradient-house-wifi.jpg` | 蓝青渐变 + 白描边房子和 wifi | 描边较粗，可用 | 烟囱是新元素；辉光在小尺寸会糊 |
| B | `B-geometric-fill-house.jpg` | 海军底 + 琥珀屋顶 + 紫青墙 | 色块大，可用 | 留白多，小尺寸房子偏小；门缝会丢 |
| C | `C-roof-barchart.jpg` | 蓝底 + 屋顶 + 五根彩色柱 | 几何块，最稳 | 原稿有烟囱 |
| D | `D-house-area-chart.jpg` | 房子轮廓内叠面积图 | 波形在 16px 会糊 | 预做圆角，开始菜单会双重缩进 |

## 选定

用户选定 C。实施真源用 `C-roof-barchart-master.jpg`：同一构图，去掉烟囱，屋顶与柱加粗铺满。
