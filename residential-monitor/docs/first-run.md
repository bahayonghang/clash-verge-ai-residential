# 首次配置

1. 配置 loopback TCP External Controller，例如 `127.0.0.1:9090`。
2. 输入 TCP secret。secret 只进入当前进程或 Credential Manager，不回显到页面、日志或 Channel。
3. 测试连接。非回环地址会被拒绝。
4. 选择重点目标并排序。名称含「家宽」的条目适合作为建议，不是强制。
5. 登录自启动默认关闭。只有用户明确确认后才允许写入。
6. 阅读本地隐私说明：数据只留本机，无遥测。
7. 通知能力预检。测试通知不写告警历史。开发态 Fake sink 不发送系统通知。

向导完成前，实时页可以打开，但未配置控制器时不能发送关闭请求。
